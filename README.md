# Test read and write excel files

- Use calamine for reading xlsx files
- Use rust_xlsxwriter for writing xlsx files

## Utils:

*data_xlsx*         - creating own table to be exported to xlsx\
*formats*           - handles excel formatting\
*read_xlsx*         - own reader\
*time_conversions*  - create Create calamine::datatype::Data::DateTime from i32, u32\
*writer_xlsx*       - own writer
